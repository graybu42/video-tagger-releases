# Video Tagger — releases

Installers for **Video Tagger**, a desktop app for tagging a personal video library
(tags, people, titles, descriptions, ratings, markers — all written into the files
themselves in standard fields).

Download the latest `Video-Tagger-Setup-x.y.z.exe` from the **Releases** tab on the right.
The app checks this page for updates on its own and installs them in the background.

Source code lives in a separate, private repository.
